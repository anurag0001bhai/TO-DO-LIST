# Python To-Do List Application

A simple command-line To-Do List application built with Python.

## Features

- Add new tasks
- View all tasks
- Update existing tasks
- Delete tasks
- Mark tasks as completed
- Automatically save tasks in `tasks.json`

## Requirements

- Python 3.x
- No external libraries are required.

## How to Run

1. Open a terminal in this project folder.
2. Run:

```bash
python todo.py
```

On some systems, use:

```bash
python3 todo.py
```

## Usage

After starting the program, select an option from the menu:

1. Add Task
2. View Tasks
3. Update Task
4. Delete Task
5. Mark Task as Completed
6. Exit

## Example

```text
============================================================

============================================================

3. Update Task
4. Delete Task
5. Mark Task as Completed

============================================================
```

## Project Objective

The objective of this project is to create a Python-based task management application that allows users to efficiently create, update, track, and manage their daily tasks.

## Technologies Used

- Python
- JSON for local data storage
- Command Line Interface (CLI)
